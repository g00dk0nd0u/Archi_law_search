# USER_MANUAL

このアプリは、`data/laws.db` に収録された法令をローカルのブラウザUIで検索するためのものです。

## Webアプリの起動方法

```bash
python -m src.prepare_sqlite --db data/laws.db
python -m src.web_app --db data/laws.db --host 127.0.0.1 --port 8765
```

ブラウザで `http://127.0.0.1:8765` を開いて使います。

## ブラウザでの使い方

- 検索フォームは左から `番号` → `検索キーワード` → `検索対象` → `検索` の順です。
- `法令` モードでは、番号欄に `条番号`、キーワード欄に本文検索語を入れます。
- `告示` モードでは、番号欄に `告示番号`、キーワード欄に告示名や本文の検索語を入れます。
- キーワード欄はスペース区切りの AND 検索です。入力中の末尾スペースは見た目上保持され、検索時に正規化されます。
- 右上の `Settings` から、収録法令の追加・更新・削除ができます。
- `127.0.0.1` / `localhost` で起動しているときは、右上の `終了` ボタンでローカル Web サーバーを停止できます。
- 告示モードの結果列は `告示番号 / 告示名 / 抜粋 / リンク` です。告示名の下には `organization` と、`document_date` から抽出した `YYYY年` が補足表示されます。リンク列は `PDF` / `HTML` / `DOCX` / `XLSX` / `LINK` の小さなボタン風UIで表示されます。
- ヒット件数バー右側の `TXT保存` は、現在の検索結果全文を `output/exports/latest_law_search.txt` または `output/exports/latest_kokuji_search.txt` に上書き保存します。
- 告示結果のリンク列には `全文コピー` ボタンが付き、クリック時に対象告示の `full_text` を個別コピーできます。
- 告示番号は `国土交通省告示` と `第1119号` のように 2 行で表示されます。

## 条番号検索

- 例: `112` / `第五十二条`
- 数字表記でも検索できます。
- 条番号検索は前方一致なので、基準条文と枝番条文をまとめて確認できます。
- 同じ条番号が複数法令にある場合は、それぞれの法令ごとに結果が表示されます。

## 告示番号検索

- 例: `1436` / `1436号` / `第1436号` / `告示第1436号`
- `建設省告示第1436号` や `国土交通省告示第1436号` のような表記でも検索できます。
- 新しい告示DBでは `document_number_digits` / `document_number_norm` を優先し、古い告示DBでは従来の文字列検索に自動フォールバックします。
- 番号表示時は `第` だけが単独で強調されないようにし、番号検索時は抽出した数字を主にハイライトします。

## キーワード検索

- 例: `容積率`
- 複数語を入れた場合は、語句を組み合わせて検索します。
- 環境によっては FTS5 を使い、使えない場合は LIKE 検索へ自動フォールバックします。

## txt保存先

- Web UI の標準保存先は `output/exports/` です。
- 標準ファイル名は `latest_law_search.txt` と `latest_kokuji_search.txt` で、毎回上書きされます。
- ローカル環境では保存後に `output/exports/` フォルダを開こうとしますが、開けない環境でも検索画面は落ちません。

## 検索できないケース

- `data/laws.db` に未収録の法令は検索できません。
- DBに未収録の改正内容や法令は、このアプリだけでは確認できません。
