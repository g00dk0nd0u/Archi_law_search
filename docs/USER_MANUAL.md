# USER_MANUAL

このアプリは、`data/laws.db` に収録された法令をローカルのブラウザUIで検索するためのものです。

## Webアプリの起動方法

```bash
python -m src.prepare_sqlite --db data/laws.db
python -m src.web_app --db data/laws.db --host 127.0.0.1 --port 8765
```

ブラウザで `http://127.0.0.1:8765` を開いて使います。

## ブラウザでの使い方

- `Article search` に条番号を入れると、条番号中心で検索できます。
- `Body keyword search` に語句を入れると、本文キーワードで検索できます。
- 右上の `Settings` から、収録法令の追加・更新・削除ができます。

## 条番号検索

- 例: `第五十二条`
- 数字表記でも検索できます。
- 条番号検索は前方一致なので、基準条文と枝番条文をまとめて確認できます。
- 同じ条番号が複数法令にある場合は、それぞれの法令ごとに結果が表示されます。

## キーワード検索

- 例: `容積率`
- 複数語を入れた場合は、語句を組み合わせて検索します。
- 環境によっては FTS5 を使い、使えない場合は LIKE 検索へ自動フォールバックします。

## 検索できないケース

- `data/laws.db` に未収録の法令は検索できません。
- DBに未収録の改正内容や法令は、このアプリだけでは確認できません。
