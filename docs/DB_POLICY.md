# DB_POLICY

`data/laws.db` は、このリポジトリの検索根拠です。法令調査では、DBに存在する法令と条文だけを回答根拠に使います。

## 現在収録済みの法令

2026-05-02 時点で `data/laws.db` の `laws` テーブルを確認した結果、収録されている法令は次の 3 件です。

- `325AC0000000201` 建築基準法
- `325CO0000000338` 建築基準法施行令
- `325AC1000000202` 建築士法

## 未収録の代表例

法令マスタ候補にはあっても、現行の `data/laws.db` に未収録のものがあります。たとえば次は未収録です。

- 建設業法
- 都市計画法
- 消防法
- 消防法施行令
- 景観法

## 運用ルール

- DBにない内容は、回答根拠にしません。
- DBで確認できない事項は、「このDB上では確認できません」と明記します。
- 未収録法令を追加する場合は、法令IDと法令名の対応を確認してから取り込みます。
- 既存DBを更新するときは、既存WebアプリとCLI検索の動作確認を行います。
