# CODEX_USAGE

このリポジトリを法令調査に使うときは、必ず `data/laws.db` を根拠にして確認します。
一般知識だけで法令回答せず、検索結果にない内容は「現在の本データベース上では確認できません」と明記してください。

## 基本ルール

- 法令調査では必ず `python -m cli.search_laws` を使います。
- macOS などで `python` が使えない場合は `python3 -m cli.search_laws` に読み替えます。
- 条番号が分かる場合は `--article` を使います。
- `--article` は前方一致検索であり、枝番条文も含めて返ります。
- 法令が分かる場合は `--law-id` を優先します。
- キーワード調査は `--query` を使います。
- 初回検索で不十分な場合のみ、検索語を変えて最大1回だけ再検索します。
- 回答には、法令名・条番号・条名・該当原文を含めます。
- 原文と解釈を混ぜません。
- 一般知識だけで法令回答しません。二次的な情報の不確定なウェブ利用は原則不可です。

## 回答フォーマット

法令調査の回答は、検索結果をそのまま並べず、原則として次の Markdown 形式に整理します。

```md
## まとめ

（DBで確認できた内容だけを短く書く）

## 根拠条文

- 法令名：
- 条番号：
- 条名：

## 原文

（該当する条文原文をそのまま引用する）
```

複数条文が関係する場合は、条文ごとに分けます。

```md
## まとめ

（複数条文を踏まえた結論を短く書く）

## 根拠条文

### 1. 建築基準法 第五十二条（容積率）

（この条文が何を定めているかを1行で書く）

### 2. 建築基準法施行令 第二条（面積、高さ等の算定方法）

（この条文が何を定めているかを1行で書く）

## 原文

### 建築基準法 第五十二条（容積率）

（該当原文）

### 建築基準法施行令 第二条（面積、高さ等の算定方法）

（該当原文）
```

## 使い方

### 条番号が分かる場合

```bash
python -m cli.search_laws --law-id 325AC0000000201 --article 第五十二条 --json-pretty
```

`--article` は前方一致なので、`第五十二条` を指定すると `第五十二条の二` などの枝番条文も一緒に確認できます。

### 法令名で絞る場合

`--law` は、DB内に完全一致する法令名があるときは完全一致で検索し、完全一致がないときだけ部分一致にフォールバックします。

```bash
python -m cli.search_laws --law "建築基準法" --article 第五十二条 --json-pretty
```

### キーワードで調べる場合

```bash
python -m cli.search_laws --query "容積率 前面道路" --limit 10 --json-pretty
```

## 回答作成時の注意

- 先にまとめを書きます。
- DBで確認できた内容だけを結論に使います。
- 条名は `article_title` や条文冒頭から確認します。
- 原文は改変しません。
- 長い条文は、意味が変わらない範囲で該当部分だけ抜粋します。
- 抜粋する場合でも、意味が変わらない範囲にします。
- DBで確認できない内容は、「このデータベース上では確認できません」と書きます。
- 網羅できない場合は、「このデータベース上で確認できた範囲では」と書きます。
- 実務上の補足は原則として書きません。
- DB外の推測を書く場合は、必ず `DB外の補足` と明示します。
- 「代表的には」「主に」「など」「おそらく」「たぶん」はなるべく使いません。
- 最後に不要な提案は書きません。

## 回答前チェック

- DBを検索したか
- 条文番号を確認したか
- 条名を確認したか
- 原文を出したか
- DB外の説明を混ぜていないか
- 回答が `結論 / 根拠条文 / 原文` の形になっているか
